# 🍔 Online Food Ordering System

## About the Project

This project is a web-based online food ordering system developed as part of the **Web Design Course (7th Semester)** at university.

The main goal of this project is to provide a platform where users can explore different restaurants, browse their menus, add food items to their shopping cart, and place orders online. Restaurants can also manage their menus, receive customer orders, update order statuses, and create discount coupons.

The system is designed to make the food ordering process easier, faster, and more convenient for both customers and restaurant owners.

## ✨ Features

### 🏪 Restaurant Panel
- User registration and login
- Restaurant profile creation and management
- Add, edit, and manage food items
- Upload food images and provide descriptions and prices
- View incoming customer orders
- Update order statuses:
  - Preparing
  - Shipped
  - Delivered
  - Cancelled
- Create and manage discount coupons

### 👤 Customer Panel
- User registration and login
- Browse available restaurants
- Search restaurants by restaurant name or food title
- View restaurant menus and food details
- Add food items to the shopping cart
- Place and manage orders
- Track order status
- Apply discount coupons during checkout

### ⭐ Additional Features
- Email and/or SMS order confirmation
- Food rating and review system
- Delivery fee calculation based on distance
- Display restaurants on an interactive map

## 🛠️ Technologies

The project is being developed using web technologies, with the following tools and frameworks:

- **Backend:** Python / Django
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite
- **Version Control:** Git & GitHub
